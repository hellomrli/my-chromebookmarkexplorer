# 查重并检查网址

[返回文档入口](index.md)

## 查看重复书签

点击“查重”扫描当前文档中的所有书签。结果按规范化网址分组，列出名称、文件夹路径和添加时间。结果窗口用于查看；返回主窗口进行移动、重命名或删除。

同一网址出现在不同主题文件夹可能是有意保留，先确认用途再删除。

## 执行测活

选择要检查的范围后执行“测活”。请求使用轻量 GET，在最终响应头到达后停止下载正文。工具跟随跳转、优先使用系统代理，并区分网络故障和服务器返回的状态。

默认并发为 8，同一主机最多 2 个请求，超时 15 秒，可在工具栏调整。临时请求故障会重试一次，部分重试回退 HTTP/1.1。无协议网址先尝试 HTTPS，旧 HTTP 网址在连接失败时可尝试 HTTPS。实时检测默认不使用结果缓存，每轮先清除本次范围的旧结果。

| 结果 | 建议 |
|---|---|
| 正常、跳转 | 保留；需要时核对最终地址 |
| 需要登录、受限、限流 | 用浏览器确认账号、代理或服务限制 |
| 404/410、无效网址 | 核实后删除或移到待处理文件夹 |
| 超时、DNS、TLS、连接错误、服务器异常 | 检查网络并稍后复测 |
| 非 HTTP 协议 | 未检测，`chrome://`、`file://` 等不会作为死链 |

## 处理异常链接

使用“删除异常链接”打开确认清单。只有明确的 404/410 或无效网址默认勾选；超时、证书和临时服务器错误要人工勾选。

也可用“移动异常链接”将结果移到指定文件夹。改动先留在内存中，检查结果后再保存。检测不是完整浏览器加载测试，脚本页面、登录态和网站风控可能导致不同结果。
